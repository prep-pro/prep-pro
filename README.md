# Prep.pro

Ferramenta da **16X Consultoria Ltda.** Todos os direitos reservados (veja `LICENSE`).

App para planejar projetos de preparação de carros com o método **As 5 Marchas**.

- `index.html`: o app (PWA, um arquivo só), publicado no Netlify a cada push na `main`.
- `sql/`: scripts do banco no Supabase, na ordem em que foram aplicados.
- A cada versão, aumente `APP_VERSION` no `index.html`: é isso que faz o app atualizar ao puxar a tela para baixo.
